🚀 АВТОМАТИЧЕСКОЕ РАЗВЕРТЫВАНИЕ ЗАВЕРШЕНО!

📁 Папка web-deploy содержит готовый к развертыванию проект

🔗 БЫСТРОЕ РАЗВЕРТЫВАНИЕ:

1. GitHub:
   - Создайте репозиторий: https://github.com/new
   - Загрузите содержимое папки web-deploy

2. Railway (Backend):
   - Перейдите: https://railway.app
   - Deploy from GitHub → выберите ваш репозиторий
   - Добавьте переменные: PORT=3000, NODE_ENV=production

3. Vercel (Frontend):
   - Перейдите: https://vercel.com
   - Import Project → выберите ваш репозиторий
   - Добавьте переменную: VITE_API_URL=[URL с Railway]

✅ ГОТОВО! Ваше приложение будет доступно в интернете

📋 Тестовые данные:
- Админ: admin / admin123
- Пользователь: user1 / password123
