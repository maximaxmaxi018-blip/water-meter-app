# 🚀 БЫСТРОЕ РАЗВЕРТЫВАНИЕ

## Вариант 1: PowerShell (рекомендуется)
1. Откройте PowerShell от имени администратора
2. Выполните: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
3. Запустите: `.\setup-and-deploy.ps1`

## Вариант 2: Командная строка
1. Откройте cmd от имени администратора  
2. Запустите: `setup-and-deploy.bat`

## Что делают скрипты:
✅ Проверяют установку Git
✅ Инициализируют Git репозиторий
✅ Добавляют все файлы в Git
✅ Создают коммит
✅ Настраивают GitHub remote
✅ Загружают код в GitHub
✅ Обновляют vite.config.ts для GitHub Pages

## После запуска скрипта:
1. Создайте репозиторий на GitHub (https://github.com/new)
2. Настройте бэкенд на Render.com
3. Включите GitHub Pages в настройках репозитория

## Если Git не установлен:
Скачайте с https://git-scm.com/download/win и установите с настройками по умолчанию.
