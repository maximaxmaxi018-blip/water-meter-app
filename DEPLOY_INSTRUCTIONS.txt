ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ НА GITHUB PAGES

1. Зайдите в ваш репозиторий: https://github.com/maximaxmaxi018-blip/water-meter-app

2. Удалите все файлы из репозитория (кроме .git папки если есть)

3. Загрузите все файлы из этой папки (github-deploy) в корень репозитория

4. В настройках репозитория (Settings > Pages) убедитесь что:
   - Source: Deploy from a branch
   - Branch: main (или master)
   - Folder: / (root)

5. После загрузки файлов сайт будет доступен по адресу:
   https://maximaxmaxi018-blip.github.io/water-meter-app/
