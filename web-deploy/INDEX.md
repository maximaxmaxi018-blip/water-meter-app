## 🔄 ПРОЦЕСС РАБОТЫ

### 1. Первый запуск (LOCAL DEVELOPMENT)

```bash
# Терминал 1 - Бэкенд
cd backend
npm install
npm start

# Терминал 2 - Фронтенд
npm install
npm run dev

# Браузер
http://localhost:3000
```

### 2. Работа с приложением

- Входите с учетными данными администратора (ADMIN / admin123)
- Или пользователя (100101-100130 / любой пароль)
- Все операции сохраняются в SQLite базу данных
- Бэкенд доступен на http://localhost:5000/api

### 3. Развертывание на Production

Следуйте инструкциям в [DEPLOYMENT.md](./DEPLOYMENT.md):
- Подготовка Linux сервера
- Установка Node.js и PM2
- Конфигурация Nginx
- SSL сертификаты
