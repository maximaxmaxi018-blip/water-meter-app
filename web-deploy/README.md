# Инструкция по загрузке проекта в GitHub

## Шаг 1: Установка Git (если не установлен)

Скачайте и установите Git с официального сайта: https://git-scm.com/download/win

## Шаг 2: Создание репозитория на GitHub

1. Перейдите на https://github.com/new
2. Назовите репозиторий: `water-meter-app`
3. Выберите "Public" или "Private"
4. НЕ добавляйте README, .gitignore или лицензию
5. Нажмите "Create repository"

## Шаг 3: Загрузка проекта

Откройте командную строку в этой папке и выполните:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/water-meter-app.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` на ваш логин GitHub.

## Шаг 4: Развертывание

После загрузки в GitHub следуйте инструкциям в файле `DEPLOYMENT_GUIDE.md`

## Структура проекта

- `backend/` - серверная часть (Node.js + Express)

- `package.json` - корневой файл с зависимостями
- `vercel.json` - конфигурация для Vercel

# 🏠 Счетчик воды - Вариант 2

Полнофункциональное веб-приложение для управления показаниями счетчиков воды, заявками на услуги и взаимодействием между пользователями и администрацией.

## ✨ Основные возможности

### Для пользователей
- 📊 Ввод и просмотр показаний счетчиков воды (ХВС и ГВС)
- 📈 Графики потребления с разделением по видам воды
- 📝 Создание заявок на поверку и замену счетчиков
- 💬 Отправка обратной связи и получение ответов администрации
- 📰 Просмотр новостей и объявлений
- 🌙 Темный режим
- 📱 Адаптивный дизайн

### Для администраторов
- 👥 Управление пользователями и их данными
- 📋 Просмотр и обработка заявок
- 👷 Управление сантехниками и назначение работ
- 📢 Публикация новостей и объявлений
- 📊 Просмотр истории показаний
- 💾 Экспорт данных в CSV и PDF
- 🔒 Управление правами доступа

## 🛠 Технологический стек

### Фронтенд
- **React 19** с TypeScript
- **Vite** для быстрой разработки и сборки
- **Tailwind CSS** для стилизации
- **Recharts** для визуализации данных
- **jsPDF + html2canvas** для генерации PDF отчетов

### Бэкенд
- **Express.js** REST API сервер
- **SQLite3** для персистентного хранилища данных
- **JWT (jsonwebtoken)** для аутентификации
- **bcryptjs** для безопасного хеширования паролей
- **CORS** для кроссдоменных запросов

## 🚀 Быстрый старт

### Требования
- Node.js v18 или выше
- npm или yarn

### Локальная разработка

#### 1. Установка зависимостей
```bash
# Фронтенд
npm install

# Бэкенд
cd backend
npm install
cd ..
```

#### 2. Запуск приложения

**Терминал 1 - Бэкенд (порт 5000)**
```bash
cd backend
npm start
```

**Терминал 2 - Фронтенд (порт 3000)**
```bash
npm run dev
```

#### 3. Открыть в браузере
```
http://localhost:3000
```

## 🔄 Интеграция

Приложение использует асинхронную интеграцию между React фронтенд-ом и Express бэкенд-ом:

- **API URL**: `http://localhost:5000/api`
- **Аутентификация**: JWT токены в localStorage
- **Синхронизация**: Все операции сохраняются в SQLite БД

Подробнее см. [INTEGRATION.md](./INTEGRATION.md)

## 🗄 База данных

### Таблицы

- **users** - Данные пользователей и администраторов
- **readings** - История показаний счетчиков воды
- **applications** - Заявки на услуги (поверка, замена)
- **news** - Новости и объявления
- **feedbacks** - Обратная связь от пользователей
- **plumbers** - Данные сантехников/специалистов

Подробное описание схемы см. в [backend/database.js](./backend/database.js)

## 🌐 API Endpoints

### Аутентификация
- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/change-password` - Смена пароля
- `GET /api/auth/verify` - Проверка токена

### Пользователи
- `GET /api/users` - Список всех пользователей
- `GET /api/users/:id` - Получить пользователя
- `POST /api/users` - Создать пользователя
- `PUT /api/users/:id` - Обновить пользователя
- `DELETE /api/users/:id` - Удалить пользователя

### Показания
- `GET /api/readings` - Все показания
- `GET /api/readings/user/:userId` - Показания пользователя
- `POST /api/readings` - Добавить показание
- `PUT /api/readings/:id` - Обновить показание
- `DELETE /api/readings/:id` - Удалить показание

### Заявки
- `GET /api/applications` - Все заявки
- `POST /api/applications` - Создать заявку
- `PUT /api/applications/:id` - Обновить заявку
- `DELETE /api/applications/:id` - Удалить заявку

[Полный список см. в INTEGRATION.md](./INTEGRATION.md#реализованные-функции-интеграции)

## 🎨 Особенности

### Графики потребления воды
- Раздельные графики для ХВС (холодной воды) и ГВС (горячей воды)
- Интерактивные подсказки при наведении
- Экспорт в PDF

### Поддержка двойных счетчиков
- Возможность учета 2 счетчиков ХВС и 2 счетчиков ГВС
- Галочка в админ-панели для активации режима
- Условное отображение полей ввода

### CSV Экспорт
- Выгрузка данных пользователей и показаний в CSV
- Включает: ФИО, поселение, адрес, показания по всем счетчикам
- Совместим с Excel и Google Sheets

### Генерация квитанций
- Автоматическая генерация PDF-квитанций
- Расчет начисленной суммы на основе показаний
- Печать и скачивание

## 🔐 Безопасность

- ✅ Пароли хэшируются bcryptjs (10 раундов)
- ✅ JWT токены для статeless аутентификации
- ✅ CORS настройки для разработки и production
- ✅ Параметризованные SQL запросы (защита от SQL injection)
- ✅ Валидация входных данных на сервере
- ⚠️ В production необходимо:
  - Изменить JWT_SECRET
  - Использовать HTTPS
  - Настроить переменные окружения
  - Включить более строгие CORS правила
