# Быстрое решение: Вход в админ-панель

## Проблема
Не получается войти в админ-панель после ввода логина и пароля.

## Решение (3 шага)

### 1. Перезагрузите backend сервер
```bash
cd backend
# Остановите текущий процесс (Ctrl+C)
npm start
```

При запуске сервер автоматически создаст/обновит администратора в БД.

### 2. Очистите кэш браузера
- Откройте DevTools (F12)
- Перейдите на вкладку Application → Storage
- Нажмите "Clear All"
- Перезагрузите страницу (Ctrl+R)

### 3. Попробуйте вход
- Нажмите "Вход для сотрудников"
- **Логин**: оставьте пустым (или введите `admin`)
- **Пароль**: `admin123`
- Нажмите "Подтвердить вход"

## Если не помогло

Удалите базу данных и пересоздайте её:
```bash
cd backend
rm water_meter.db
npm start
```

## Что должно произойти
✅ Админ-панель загружается с реестром абонентов
✅ В консоли браузера видны логи входа
✅ Вверху страницы зеленое сообщение "✅ Админ-панель успешно загружена!"
