# 🚀 Пошаговое развертывание в интернете

## Шаг 1: Подготовка проекта (5 минут)

1. Откройте PowerShell в папке проекта и выполните:
```powershell
.\deploy-simple.ps1
```

Это установит все зависимости и создаст production build.

## Шаг 2: Развертывание бэкенда на Railway (10 минут)

### 2.1 Регистрация
1. Перейдите на https://railway.app
2. Нажмите "Start a New Project"
3. Войдите через GitHub или создайте аккаунт

### 2.2 Создание проекта
1. Нажмите "Deploy from GitHub repo" или "Empty Project"
2. Если выбрали "Empty Project", нажмите "Deploy from GitHub repo"
3. Подключите GitHub аккаунт (если нужно)

### 2.3 Загрузка кода
**Вариант A: Через GitHub (рекомендуется)**
1. Создайте репозиторий на GitHub
2. Загрузите туда папку `backend`
3. Выберите репозиторий в Railway

**Вариант B: Прямая загрузка**
1. Выберите "Empty Project"
2. Перетащите папку `backend` в Railway

### 2.4 Настройка переменных окружения
В Railway Dashboard добавьте переменные:
- `NODE_ENV`: `production`
- `PORT`: `3000`
- `JWT_SECRET`: `your-super-secret-jwt-key-12345`
- `FRONTEND_URL`: `*` (пока что, обновим позже)

### 2.5 Деплой
1. Railway автоматически запустит деплой
2. Дождитесь зеленой галочки
3. **СКОПИРУЙТЕ URL** (например: `https://backend-production-xxxx.up.railway.app`)

## Шаг 3: Развертывание фронтенда на Vercel (10 минут)

### 3.1 Регистрация
1. Перейдите на https://vercel.com
2. Нажмите "Start Deploying"
3. Войдите через GitHub

### 3.2 Создание проекта
1. Нажмите "New Project"
2. Выберите "Import Git Repository" или загрузите папку

### 3.3 Загрузка кода
**Вариант A: Через GitHub**
1. Выберите ваш репозиторий
2. Vercel автоматически обнаружит React проект

**Вариант B: Прямая загрузка**
1. Перетащите папку проекта (НЕ папку dist!)
2. Vercel сам соберет проект

### 3.4 Настройка переменных окружения
В разделе "Environment Variables" добавьте:
- Ключ: `VITE_API_URL`
- Значение: URL вашего бэкенда с Railway (например: `https://backend-production-xxxx.up.railway.app/api`)

⚠️ **ВАЖНО**: Добавьте `/api` в конце URL!

### 3.5 Деплой
1. Нажмите "Deploy"
2. Дождитесь завершения
3. **СКОПИРУЙТЕ URL** фронтенда

## Шаг 4: Финальная настройка (5 минут)

### 4.1 Обновите CORS на бэкенде
1. Вернитесь в Railway Dashboard
2. Обновите переменную `FRONTEND_URL` на URL вашего фронтенда
3. Перезапустите деплой

### 4.2 Тестирование
1. Откройте URL фронтенда
2. Попробуйте войти с тестовыми данными:
   - Лицевой счет: `12345`
   - Пароль: (будет сгенерирован автоматически)

## 🎉 Готово!

Ваше приложение теперь доступно в интернете:
- **Фронтенд**: https://your-app.vercel.app
- **Бэкенд**: https://backend-production-xxxx.up.railway.app

## 🔄 Обновления

Для обновления приложения:
1. Внесите изменения в код
2. Загрузите обновленные файлы на GitHub
3. Railway и Vercel автоматически пересоберут проект

## 🆘 Решение проблем

### Фронтенд не подключается к бэкенду
1. Проверьте переменную `VITE_API_URL` на Vercel
2. Убедитесь, что URL заканчивается на `/api`
3. Проверьте, что бэкенд запущен (откройте URL бэкенда + `/health`)

### CORS ошибки
1. Обновите `FRONTEND_URL` на Railway
2. Перезапустите бэкенд

### Бэкенд не запускается
1. Проверьте логи в Railway Dashboard
2. Убедитесь, что все переменные окружения установлены
