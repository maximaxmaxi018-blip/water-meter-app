# Чек-лист: Проверка входа в админ-панель

## Подготовка
- [ ] Backend сервер запущен (`npm start` в папке `backend`)
- [ ] Frontend сервер запущен (`npm run dev` в корневой папке)
- [ ] Браузер открыт на `http://localhost:5173`

## Очистка кэша
- [ ] Открыт DevTools (F12)
- [ ] Перейдена вкладка Application/Storage
- [ ] Очищены localStorage и sessionStorage
- [ ] Перезагружена страница (Ctrl+R)

## Вход администратора
- [ ] Нажата кнопка "Вход для сотрудников" в нижней части страницы
- [ ] Открылось модальное окно входа
- [ ] Поле "Логин доступа" оставлено пустым (или введено `admin`)
- [ ] В поле "Пароль" введено `admin123`
- [ ] Нажата кнопка "Подтвердить вход"

## Проверка консоли браузера (F12 > Console)
- [ ] Видны логи: `Admin auth attempt with accountNumber: ADMIN`
- [ ] Видны логи: `Admin login response: {...}`
- [ ] Видны логи: `Response user isAdmin: 1 type: number`
- [ ] Видны логи: `isAdmin after conversion: true`
- [ ] Видны логи: `Setting currentUser with isAdmin: true`
- [ ] Видны логи: `Admin authentication successful`
- [ ] Видны логи: `✓ AdminPanel rendering with user: ADMIN isAdmin: true`

## Проверка консоли сервера
- [ ] Видны логи: `✓ Password valid for user: ADMIN isAdmin: 1 type: number`
- [ ] Видны логи: `✓ isAdmin converted to boolean: true`
- [ ] Видны логи: `✓ Returning login response with isAdmin: true type: boolean`

## Проверка админ-панели
- [ ] Модальное окно входа закрылось
- [ ] Загрузилась админ-панель
- [ ] Видна зеленая полоса: "✅ Админ-панель успешно загружена!"
- [ ] Видна таблица "Реестр абонентов"
- [ ] Видны кнопки управления (Редактировать, История)
- [ ] Видны вкладки: Абоненты, Заявки, Сантехники, Новости, Отзывы, Отчеты

## Проверка функциональности
- [ ] Можно переключаться между вкладками
- [ ] Можно нажать кнопку "Обновить" для загрузки данных
- [ ] Можно нажать кнопку "Импорт" для загрузки CSV
- [ ] Можно нажать кнопку "+ Абонент" для добавления нового абонента
- [ ] Можно выйти из админ-панели (кнопка выхода в верхнем правом углу)

## Проверка ошибок доступа
- [ ] Если попытаться войти с неправильным паролем, показывается ошибка
- [ ] Если попытаться войти с пользователем без прав админа, показывается сообщение об ошибке доступа

## Проверка восстановления сессии
- [ ] Перезагрузить страницу (F5)
- [ ] Проверить, что админ остается в системе (не требуется повторный вход)
- [ ] Админ-панель загружается автоматически

## Проверка выхода
- [ ] Нажать кнопку выхода (красная кнопка в верхнем правом углу)
- [ ] Проверить, что вернулись на главную страницу
- [ ] Проверить, что localStorage очищен

## Результат
- [ ] ✅ Все пункты выполнены
- [ ] ✅ Админ-панель работает корректно
- [ ] ✅ Вход/выход работает правильно
- [ ] ✅ Логирование показывает правильные значения

## Если что-то не работает
1. Проверьте консоль браузера (F12 > Console) на ошибки
2. Проверьте консоль сервера на ошибки
3. Удалите БД: `rm backend/water_meter.db`
4. Перезагрузите сервер: `npm start` в папке `backend`
5. Очистите кэш браузера и попробуйте снова
