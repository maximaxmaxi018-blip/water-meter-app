# Тестирование синхронизации данных

## Быстрый тест

### Шаг 1: Первое устройство
1. Откройте приложение в браузере
2. Войдите под любым аккаунтом (например: 12345)
3. Добавьте показания счетчиков
4. Создайте заявку на услугу
5. Отправьте сообщение в обратной связи

### Шаг 2: Второе устройство  
1. Откройте приложение в другом браузере/устройстве
2. Войдите под тем же аккаунтом (12345)
3. **Проверьте:**
   - ✅ Показания отображаются в истории
   - ✅ Заявка видна в разделе "Мои услуги"
   - ✅ Сообщение есть в обратной связи
   - ✅ Личные данные одинаковые

### Шаг 3: Обратная синхронизация
1. На втором устройстве добавьте новые показания
2. Вернитесь к первому устройству
3. Обновите страницу или перезайдите
4. **Проверьте:** новые данные появились

## Ожидаемый результат

🎯 **Все данные должны быть доступны с любого устройства**

Если данные не синхронизируются:
- Проверьте работу сервера (backend должен быть запущен)
- Убедитесь, что используется один и тот же аккаунт
- Проверьте консоль браузера на ошибки

## Логи в консоли

При успешной синхронизации вы увидите:
```
✓ Данные пользователя синхронизированы с сервера: {readings: X, applications: Y, feedbacks: Z}
✅ Показания сохранены на сервер и добавлены локально
✅ Заявка сохранена на сервер и добавлена локально  
✅ Сообщение сохранено на сервер и добавлено локально
```
